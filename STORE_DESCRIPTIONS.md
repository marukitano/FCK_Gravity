# Store descriptions

## Deutsch

### Kurzbeschreibung

Ein schwerkraftgesteuertes Vektor-Ziffernblatt für die Pebble Time 2.

### Beschreibung

Gravity ist ein minimalistisches, schwerkraftgesteuertes Ziffernblatt für die
Pebble Time 2. Die vier Ziffern drehen sich als zusammenhängende Anzeige und
bleiben beim Bewegen des Handgelenks aufrecht.

Eine feste virtuelle Kegelbahn verhindert Zittern, wenn die Uhr nahezu
waagerecht gehalten wird. Eine gleichmäßige Winkeldeadzone ignoriert kleine
unbeabsichtigte Bewegungen, während eine gedämpfte Federbewegung für ein
dezentes und natürliches Übersteuern sorgt.

Die Ziffern werden als Vektorgrafiken gezeichnet. Unterstützt werden das
12- und 24-Stunden-Format.

Gravity basiert auf dem ursprünglichen Pebble-Watchface Upright von Jnm und
wurde für die Pebble Time 2 vollständig modernisiert.

## English

### Short description

A gravity-driven vector watchface for the Pebble Time 2.

### Description

Gravity is a minimalist, gravity-driven watchface for the Pebble Time 2. Its
four digits rotate as one unified display and remain upright as the wrist
moves.

A fixed virtual cone orbit prevents jitter when the watch is held nearly flat.
A consistent angular deadzone ignores small unintended movements, while a
damped spring motion adds a subtle and natural overshoot.

The digits are rendered as vector graphics. Both 12-hour and 24-hour time
formats are supported.

Gravity is based on the original Pebble watchface Upright by Jnm and has been
fully modernized for the Pebble Time 2.
